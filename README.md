A simple C++ launcher with one fix for a unity game called Swords & Slippers.

Supports all versions from v0.0.10 to v0.0.13 and above - uses fallback autoscan mechanism if no known versions found.

Building:

Download Visual Studio Community https://visualstudio.microsoft.com/downloads/

Choose Classic Desktop C++

When installation finishes open Launcher.sln and hit F7 or click build solution
